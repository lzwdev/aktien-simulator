# 📈 Aktien Simulator

Ein moderner Aktien-Simulator mit Echtzeit-Kursen, Portfolio-Verwaltung und Bestenliste.

## Features

- ✅ Echtzeit-Aktienkurse (alle 5 Sekunden aktualisiert)
- ✅ Benutzerregistrierung und Login
- ✅ Portfolio mit Kauf/Verkauf
- ✅ Bestenliste mit Rangliste
- ✅ 10.000€ Startguthaben
- ✅ Mobile-optimiertes Design
- ✅ Responsive UI mit Tailwind CSS

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: Node.js, Express
- **Datenbank**: SQLite (better-sqlite3)
- **Deployment**: Render (Backend), Vercel (Frontend)
